## Known limitations
- Doctors write by hand; there is no doctor login or digital prescription (by design for the current RHC workflow).
- Fees are **references only** – no receipts, cash, refunds or cancellations until Phase 3 (billing).
- *Admitted* status is reserved for the future IPD module (no bed management yet).
- Printing is through the browser; a printer cannot be selected silently by a web page. "Save as PDF" uses the browser's PDF printer.
- After restoring an older backup, numbers issued after that backup can be issued again (the restored database does not contain those patients). Paper slips printed after the backup should be re-registered.
- Interface language is English (Urdu planned).
- Laboratory, Pharmacy, X-Ray and Ultrasound histories will be added to the patient profile in their phases.
